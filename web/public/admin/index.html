How we count
  • Players are browsers that started a game. Each one counts once a day.
  • Visitors are browsers that opened the game page. Each one counts once a day.
  • A browser is its internet address together with the browser's name. The server hashes that pair with a code that changes every Belgian day.
  • Two people at home on one connection with the same browser count as one.
  • One person on a phone and on a laptop counts as two.
  • A phone that moves from Wi-Fi to mobile data can count twice.
  • Nobody can be recognised on a later day. A period of several days adds up each day's count.
  • Different players come from the names in the login log. Players together have their name in the game. Players alone have the name they typed, which nobody checks. Players alone who typed no name are missing.
  • Time played adds a minute for each full minute of play with the game in view. A game shorter than a minute adds nothing.
  • Most at once is the highest number playing at the same moment. The server checks every second.
  • Not counted: your own visits and games as admin. Browsers that ask not to be tracked. Bots and link previews. Pages loaded ahead of time.
  • Today starts at 00:00 Belgian time. It is compared with yesterday until the same time.
  • The server has no STATS_SECRET yet. Until it has one, a restart can count a visitor again.

Two-step login

With two-step login on, logging in as admin also asks for a 6-digit code from an app on your phone: Google Authenticator, Microsoft Authenticator, 1Password, Bitwarden or any other. Someone who learns the admin password still can't get in.
