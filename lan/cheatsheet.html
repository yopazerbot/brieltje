Start a local game server

Brieltje on your own laptop for a LAN night.

Players typehttps://lan.brieltje.be

1 Once, at home needs the internet

Docker

  1. Install Docker Desktop (docker.com).
  2. Start it. Wait until it says it is running.

Cloudflare token

  1. Open dash.cloudflare.com.
  2. Go to Manage Account › Account API Tokens. My Profile › API Tokens works too.
  3. Create Token. Pick the Edit zone DNS template.
  4. Add a second permission: Zone · Zone · Read.
  5. Zone Resources: Specific zone · brieltje.be.
  6. Leave IP filtering empty.
  7. Create the token. Copy it. Cloudflare shows it only once.

First start

  1. Double-click lan.cmd in the game's folder.
  2. The first time it builds Caddy. That takes a few minutes.
  3. Paste the token at The token (not shown). Right-click pastes. Nothing shows on screen.
  4. Answer the questions (see step 3).
  5. Wait for Certificate valid until ….
  6. Press Enter to stop.

The certificate lasts 90 days. Caddy renews it whenever lan.cmd runs with internet. Start once at home in the weeks before a night.

2 The network once per venue

Router

  • Give the laptop a fixed address with a DHCP reservation.
  • Put the laptop on a cable if you can.
  • Players' Wi-Fi must let devices reach each other. Turn off client isolation.

Local DNS

  • Add one A record: lan.brieltje.be → the laptop's address.
  • Only that name. Not a whole zone.
  • Allow that name past the router's rebinding protection.

lan.cmd also points the public record at the laptop on every start with internet. Phones that skip your DNS still find it that way.

3 On the night

Start

  1. Start Docker Desktop.
  2. Double-click lan.cmd.
  3. Answer its questions:
Which network?
Enter takes the first. It is usually right.
Make it Private?
Type y on your own network.
Fix the firewall?
Enter. Then Yes in the Windows prompt.
Admin password
At least 8 characters. Only for tonight.
  1. Wait until it shows Players type this.

Run the evening

  • Players: https://lan.brieltje.be
  • You: /admin/. Log in as admin. Then Host.
  • Big screen: /admin/scores/. Press F for full screen.
  • Watch players: /admin/watch/. One player, or four side by side.
  • Leave the lan.cmd window open. It follows a change of network on its own.

Stop

  • Press Enter or Q in the lan.cmd window.
  • Accounts stay in Docker for next time. Tonight's scores start fresh.

4 When something goes wrong

What you seeWhat to do
Docker is not runningStart Docker Desktop. Wait until it runs. Start lan.cmd again.
A phone finds no site at lan.brieltje.beCheck the local DNS record. It must point at the laptop's address. Check the rebinding exception.
The name is found. The page doesn't load.Windows keeps players out. Close lan.cmd. Start it again. Answer y to Private and Enter to the firewall.
A phone on Wi-Fi can't reach it. A laptop on cable can.Client isolation is on for that Wi-Fi. Turn it off in the access point.
Cloudflare refused the tokenMake a new token. Start lan.cmd -NewToken and paste it.
Port 443 is in use by …Close the program it names. Start lan.cmd again.
No internet and no certificateBest: start once where there is internet. Or type y for plain http. Players then type the address it shows. Passwords then travel unencrypted.
This computer's address changedlan.cmd moves the public record itself. Update the local DNS record to the new address.
Caddy keeps stoppingStop with Enter. Start lan.cmd again. Its log is in the folder below.
The certificate runs out within three weeksStart lan.cmd once with internet. Caddy renews it.

5 Options

Run them in a terminal in the game's folder, for example .\lan.cmd -Http.

OptionWhat it does
-Address 192.168.1.10Uses this address instead of the one it picks.
-HttpPlain http on the laptop's address. No name. No certificate.
-Http -Port 8090Plain http on another port.
-NewTokenAsks for the Cloudflare token again.
-Domain spel.brieltje.beAnother name under brieltje.be. It gets its own certificate.
-StagingLet's Encrypt's test service. Browsers don't trust it. Only for trying out.
